Design — Local dev & deployment

docker-compose for local, two gcloud run deploy commands for production.

Local development

docker-compose up
frontend → http://localhost:3000  (Next.js dev server)
backend → http://localhost:8000  (FastAPI + uvicorn)
frontend/.env.local:
  BACKEND_URL=http://backend:8000
  NEXTAUTH_URL=http://localhost:3000
  GOOGLE_CLIENT_ID=... (from op run)
backend/.env:
  SNOWFLAKE_PAT=... (from op run)
  ANTHROPIC_API_KEY=... (from op run)
James runs only: cd frontend && npm run dev
Backend auto-starts via compose with hot-reload

Cloud Run deployment

Two deploy commands (manual, same as today)
# Backend (deploy first)
gcloud run deploy is-scoping-backend \
  --source backend/ \
  --region us-central1 \
  --no-allow-unauthenticated \
  --vpc-connector is-scoping-tool-vpc \
  --set-secrets="SNOWFLAKE_PAT=...,ANTHROPIC_API_KEY=..."

# Frontend (deploy second)
gcloud run deploy is-scoping-frontend \
  --source frontend/ \
  --region us-central1 \
  --allow-unauthenticated \
  --set-env-vars="BACKEND_URL=https://is-scoping-backend-[hash].run.app" \
  --set-secrets="GOOGLE_CLIENT_ID=...,GOOGLE_CLIENT_SECRET=...,NEXTAUTH_SECRET=..."
