Cloud Run services

is-scoping-frontend (public)
Runtime: Node 20
Auth: NextAuth.js + Google
Calls: is-scoping-backend (internal)
No VPC connector needed
Secrets: Google OAuth client, cookie secret
is-scoping-backend (internal)
Runtime: Python 3.11
Auth: Cloud Run invoker IAM only
VPC connector: is-scoping-tool-vpc
Egress IP: 35.192.132.11 (Snowflake)
Secrets: Snowflake PAT, Anthropic key

Request flow

Browser → frontend (Next.js, public URL)
    ↓ NextAuth session check
    ↓ /api/[route] proxy
frontend → backend (Cloud Run internal URL, service account token)
    ↓ FastAPI routes
backend → Snowflake (via VPC → 35.192.132.11)
backend → Anthropic API (prose generation)
